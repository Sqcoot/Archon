# AI Operating Layer

This directory is the index for Archon's agentic workflow governance docs.

- [Agentic Coding Operating Guide](agentic-coding-operating-guide.md): operating model for context, process, assurance, workflows, artifacts, gates, and validation.
- [Workflow Compliance Matrix](workflow-compliance-matrix.md): current mapping from guide requirements to actual repo assets.
- [BMAD to Archon Mapping](bmad-to-archon-mapping.md): mapping from `_bmad` install metadata and BMAD phases to Archon workflows, commands, artifacts, and gates.
- [Workflow Validation](workflow-validation.md): how to validate workflow, command, script, and repo gates.
- [Artifact Schema](artifact-schema.md): required sections for workflow handoff artifacts and the mechanical completeness check.
- [Worktree and Branch Lifecycle](worktree-and-branch-lifecycle.md): policy for isolation, branch handling, resume, abandon, complete, and cleanup.
- [Security and Secrets](security-and-secrets.md): secret handling and command safety rules for workflow assets.
- [Source Traceability](source-traceability.md): original source ideas mapped to repo decisions.
- [DRI Ownership](dri-ownership.md): ownership placeholders and review cadence for the AI operating layer.
- [Runtime Enforcement Decision](runtime-enforcement-decision.md): STAB-002 v1 enforcement choices and deferrals.
- [Runtime Enforcement Ledger](runtime-enforcement-ledger.md): reviewable decision/validation ledger for runtime-enforcement follow-up.
- [STAB-002 Validation Report](stab-002-validation-report.md): evidence trail for this operationalization patch.
- [STAB-002 Runtime Validation Report](stab-002-runtime-validation-report.md): evidence trail for runtime-enforcement v1.

The guide is the operating model. The compliance matrix is the current source of truth for repo coverage. The BMAD mapping connects `_bmad` to Archon workflows and commands. The runtime decision and ledger explain what is enforced mechanically now. Validation reports record what was actually checked.
